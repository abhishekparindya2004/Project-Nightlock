SKY EXPLORER
============

This project remains in `sky-explorer-for-abhishek/`:

  sky-explorer.html
  css/nightlock-explorer.css
  js/nightlock-explorer.js
  images/spherex/                    SPHEREx images and target metadata

The NightLock server explicitly serves this page and its local assets. Homepage
"Our mission" links open this page; the page header links back to Home and to
the Observatory. Its logo, navigation, typography, and colors follow the main
NightLock site.

Open `http://127.0.0.1:8011/sky-explorer-for-abhishek/sky-explorer.html` while
the local server is running. To refresh the images after processing, export
the new data into this folder's `images/spherex/` directory.
